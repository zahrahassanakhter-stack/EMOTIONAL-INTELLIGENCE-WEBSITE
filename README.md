# Emotional Intelligence Lab

## About the Project
Emotional Intelligence Lab is a web-based project designed to help users understand and assess their emotional intelligence through an interactive questionnaire.

## Features
- User login and signup interface
- Emotional intelligence assessment with 15 questions
- Interactive quiz navigation
- Dashboard for displaying assessment results
- Forgot password, OTP verification, and password reset interface
- Responsive user interface
- Light and dark theme styling

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage

## Project Status
The frontend has been developed. Backend integration, database connectivity, secure authentication, and email-based OTP verification are planned for future development.

## Purpose
The purpose of this project is to provide an interactive platform for exploring emotional awareness, self-management, and empathy.
